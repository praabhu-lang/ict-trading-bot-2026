# Cloud Run Infrastructure & Deployment Operations\n## ICT 0DTE Multi-Strategy Algorithmic Trading Platform\n\n### 1. Serverless Cloud Run Topology\nRuns containerized Streamlit (`src/dashboard.py`) on Google Cloud Run (`ai-trading-dashboard`) on port `8080` with `PYTHONPATH=/app`.\n\n### 2. Environment Configuration (`env.yaml`)\nExplicit string-quoted secrets for Alpaca API (`APCA_API_KEY_ID`, `APCA_API_SECRET_KEY`), Tavily, and Nvidia integration.\n\n### 3. Deployment Commands\n`gcloud run deploy ai-trading-dashboard --source . --region us-central1 --allow-unauthenticated --env-vars-file env.yaml`
